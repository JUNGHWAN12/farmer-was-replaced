# 수업 허브 · 해양교육 연계 주제탐구 (프로그래밍)

프로그래밍 게임 **The Farmer Was Replaced**로 알고리즘과 자동화를 배우고, 이를 해양 문제(스마트 양식, 해양 정화 드론 등)와 연결해 주제탐구까지 이어 가는 수업용 웹페이지입니다.

## 학생 사용법

1. 화면 위쪽에 **학번**과 **이름**을 입력하고 **저장**을 누릅니다. 저장하면 칸이 잠깁니다.
   - 다른 학번·이름으로 바꾸려면 **변경**을 누릅니다. 바꾸면 선생님 화면에 다른 학생으로 기록됩니다.
   - 다른 컴퓨터에서도 같은 학번·이름을 넣으면 미션 완료 기록을 불러옵니다.
2. 차시 탭에서 미션을 열고 **코드 복사** → 게임 코드 창에 붙여 넣어 실행합니다.
3. 미션을 마치면 **미션 완료**, 막히면 **선생님, 도와주세요**를 누릅니다.
4. 미션 아래 **코드 공유** 칸에서 내 코드를 공유하거나 친구 코드를 보고 복사할 수 있습니다.
5. 5교시에는 챌린지 결과(개선 전·후 수확과 행동 수)를 **기록 보내기**로 제출합니다.

인터넷이 잠깐 끊겨도 기록은 컴퓨터에 보관했다가 연결되면 자동으로 보냅니다.
"먼저 해금하기"와 "할 일" 체크 표시는 그 컴퓨터에만 저장됩니다.

## 선생님 화면

- **미션 진도**: 학생별 미션 완료(초록)와 도움 요청(주황)을 학번 순으로 보여 줍니다. 1초마다 새로 고칩니다.
- **마지막 기록**: 학생마다 마지막으로 기록을 보낸 시간을 보여 주고, 10분 넘게 기록이 없으면 주황색으로 강조합니다.
- **숨기기**: 테스트 이름이나 오타로 생긴 이름을 표에서 숨깁니다. 이 컴퓨터에만 적용되고 원본 기록은 지우지 않습니다.
- **도움 요청**: 오래된 요청부터 보여 주고, **해결**을 누르면 목록에서 사라집니다.
- **5교시 기록판**: 행동 1회당 수확량이 얼마나 좋아졌는지(개선율)로 순위를 매깁니다.
- **공유된 코드**: 학생들이 공유한 코드를 미션별로 보고, 부적절한 코드는 **내리기**로 학생 화면에서 내립니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 학생 화면 (차시별 미션, 코드, 체크리스트, 코드 공유) |
| `teacher.html` | 선생님 화면 (진도표, 도움 요청, 챌린지 기록판, 공유 코드 관리) |
| `apps-script/Code.gs` | 기록을 저장하는 서버 (Google Apps Script) |

별도 빌드 없이 HTML 파일만으로 동작합니다.

## 처음 설정하기

### 1. 서버 (Google 스프레드시트 + Apps Script)

1. 새 Google 스프레드시트를 만들고 **확장 프로그램 > Apps Script**를 엽니다.
2. `apps-script/Code.gs` 내용을 붙여 넣고, 맨 위 `KEY`(수업 코드)를 원하는 값으로 바꿉니다.
3. **배포 > 새 배포 > 유형: 웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 배포 후 나오는 **웹 앱 URL**을 복사합니다.
5. 함수 목록에서 `testServer`를 골라 실행하고, 실행 로그에 "정상입니다"가 나오는지 확인합니다.

> `doPost`, `doGet`은 화면이 요청할 때 Google이 실행하는 함수라서 편집기에서 직접 실행하지 않습니다.

### 2. 화면 연결

`index.html`과 `teacher.html` 두 파일 모두에서 아래 두 줄을 바꿉니다.

```js
const API = "웹 앱 URL";
const KEY = "Code.gs의 KEY와 같은 값";
```

### 3. 서버 코드를 고친 뒤 다시 배포할 때

**배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전 > 배포**를 누릅니다.
"새 배포"를 만들면 웹 앱 URL이 바뀌어서 두 HTML 파일의 `API`도 다시 고쳐야 합니다.

## 기록 데이터

기록은 스프레드시트의 시트별로 한 줄씩 쌓입니다. 열 순서는 모두 `[시간, 학생, 미션, 값, 추가 정보(JSON)]`입니다.

| 시트 | 값 | 추가 정보 |
|---|---|---|
| `progress` | `done` / `undone` | - |
| `help` | `open` / `resolved` | - |
| `challenge` | `record` | `{bg, ba, ag, aa}` 개선 전·후 수확과 행동 수 |
| `share` | `post` / `hide` / `show` | `{id, note, code}` 공유 코드 |

학생 이름은 `학번 이름`(예: `10305 홍길동`) 형식으로 저장됩니다.

## 알아 두기

- 수업 코드(`KEY`)는 학생 화면 코드에 들어 있어서 완전한 보안 장치가 아닙니다. 수업용 기록만 다루세요.
- 선생님 화면은 1초마다 서버에 요청합니다. Apps Script는 응답에 1~3초가 걸려서 실제로는 응답이 오는 대로 갱신되고, 오래 켜 두면 Apps Script 하루 실행 시간 한도에 걸릴 수 있습니다. 위쪽에 "불러오지 못함"이 계속 뜨면 `teacher.html`의 `setInterval(load, 1000)` 간격을 늘려 주세요.
